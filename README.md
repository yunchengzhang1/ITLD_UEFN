# ITLD_UEFN
Unreal Editor for Fortnite, or UEFN, 
a game development engine that creates projects to publish in Fortnite
Why are we using it?
Course Goal  ->  Why UEFN?
The goal of this course is to give students practical working knowledge of the tools, vocabulary, and techniques of 3D game level design.
that means:
You will be building levels in a game engine
You will be doing a lot of playtests and critiques with their levels
With tons of built-in components, assets within the Fortnite ecosystem, UEFN will help you complete such tasks without:
Spending hours on choosing, installing, or implementing your own character locomotion system.
Creating your own level block-out assets (but you can still import).
Sending game builds back-and-forth for critique.
